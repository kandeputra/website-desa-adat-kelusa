# Website Desa Adat Kelusa

Website resmi Desa Adat Kelusa, Kecamatan Payangan, Kabupaten Gianyar, Bali.

Satu file statis (`index.html`) tanpa build. Halaman berpindah lewat tautan `#` (contoh: `#sejarah`, `#lembaga-sabha-desa`, `#produk-hukum`).

## Menu
Beranda · Tentang Desa · Lembaga Adat · Keagamaan · Pariwisata · Keuangan & Laporan · Informasi · Layanan

## Mengisi data
Bagian bertanda kotak putus-putus emas (class `isi`) menunggu data resmi: nama prajuru, kelian banjar, kontak sekretariat, angka laporan, foto, dan akun media sosial. Berita, pengumuman, dan pararem tersimpan sebagai data di bagian `<script>` (`BERITA`, `PENGUMUMAN`, `HUKUM`, `LEMBAGA`, `WISATA`, `FAQ`).

## Publikasi
Aktifkan GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
